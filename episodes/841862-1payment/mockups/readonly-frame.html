Что такое readonly-класс в PHP?

readonly class User
{
    public function __construct(
        public string $name,
        public Address $address,
    ) {}
}

$user->name = 'Alex';Error: Cannot modify readonly property User::$name
🔒
Одно присваиваниеПосле инициализации изменить нельзя
C
Все свойства readonlyМодификатор класса применяется ко всем свойствам
P
Readonly-свойство Можно пометить одно свойство, не весь класс public readonly string $name;
Ограничение 01
У свойства должен быть тип
readonly class User {
  public $name;
} ✕ Readonly property User::$name must have type
Ограничение 02
Свойство не может быть static
public static string
$name; ✕ Static property User::$name cannot be readonly
Ограничение 03
Нельзя создать dynamic property
$user->extra = 1; ✕ Cannot create dynamic property User::$extra

∞

Важно: readonly снижает риск случайного накопления состояния, но не является общей защитой от memory leaks.
