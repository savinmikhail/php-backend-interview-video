## Аудит содержания

| Прозвучало | Оценка | Действие |
|---|---|---|
| Для ORM entities транзакцию может вести Doctrine | корректно для одного `flush()` | показать implicit transaction |
| Для raw SQL/DBAL явная транзакция может понадобиться | корректно | показать общий atomic boundary |
| DQL/QueryBuilder определяет необходимость транзакции | опасное упрощение | исправить: важна атомарность операции, а не язык запроса |

### Намеренно не показываем

- Isolation levels, savepoints, optimistic и pessimistic locking.
- Ручной `begin/commit/rollback` как единственный API: предпочтительна
  безопасная control abstraction.

## Задача визуализации

Развести автоматическую транзакцию одного `flush()` и явную границу сложной
атомарной операции.
