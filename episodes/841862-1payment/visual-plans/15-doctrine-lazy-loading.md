## Аудит содержания

| Тезис | Оценка | Действие |
|---|---|---|
| Lazy не грузит relation заранее | корректно | показать proxy/collection до обращения |
| Перебор может породить N+1 | корректно | показать один запрос списка и N запросов связей |
| Отличие EXTRA_LAZY не вспомнил | неполный ответ | дать короткое уточнение с `count()` без полной загрузки |

Не показываем все fetch modes, hydration и настройку mapping.

### Намеренно не показываем

- Полный API `PersistentCollection` и все операции EXTRA_LAZY.
- Настройку associations атрибутами/XML/YAML: она не помогает понять механизм.

## Задача визуализации

Показать, когда отложенная загрузка экономит ресурсы, когда превращается в
N+1 и какую проблему отдельно решает EXTRA_LAZY.

## Финальный экранный текст

| Элемент | Текст |
|---|---|
| Lazy | `Нет обращения → relation не загружен` |
| Риск | `1 query + N queries` |
| Extra lazy | `count() без полной загрузки collection` |

## Анимация

- В N+1 SQL-строки появляются вслед за перебором карточек.
- В EXTRA_LAZY счётчик отделяется от полной коллекции.
