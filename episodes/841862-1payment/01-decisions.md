# Редакционные решения

Все решения сначала получают статус `PROPOSED`, затем `ACCEPTED` или
`REJECTED`. Монтаж начинается после принятия решений уровня P0.

| Решение | Статус | Обоснование |
|---|---|---|
| Основная аудитория — опытные PHP-разработчики | ACCEPTED | Соответствует позиционированию канала |
| Не продавать нарратив «войти в IT» | ACCEPTED | Не соответствует целевой аудитории |
| Сократить бытовое вступление и заключение исходного интервью | PROPOSED | Оставить только контекст вакансии и техническую ценность |
| Сделать собственный cold open длительностью 20–30 секунд | PROPOSED | Быстро сформулировать обещание ролика |
| Завершить ролик авторским разбором на 60–90 секунд | PROPOSED | Дать выводы и честно разобрать ошибки |
| Не клонировать голос собеседника | PROPOSED | Сохранить прозрачность и достоверность |
| Повреждённые вопросы восстановить текстом или голосом автора | PROPOSED | Сохранить полезные ответы из блока 35–42 минуты |
| Все реконструкции явно маркировать | PROPOSED | Не выдавать восстановленное за оригинал |
| Доснимать только важные неправильные ответы | PROPOSED | Не раздувать хронометраж и стоимость монтажа |
| Основной CTA — бесплатная платформа и «пройти этот тех» | PROPOSED | Органично продолжает образовательную ценность |
| Менторство оставить вторичным CTA | PROPOSED | Не прерывать техническое позиционирование прямой продажей |
| Сделать публичной отдельную безопасную страницу интервью | PROPOSED | Нужна анонимизация и отсутствие административных данных |
| Сохранить анимированные аватары и движущуюся дымку | ACCEPTED | Базовый видеоряд уже динамический |
| Использовать центр экрана для кода, схем и тезисов | PROPOSED | Повышает информационную насыщенность |
| Не использовать музыку под всем интервью | PROPOSED | Музыка может мешать технической речи |
| Использовать музыку только в cold open, переходах и финале | PROPOSED | Добавляет ритм без постоянной нагрузки |
| Сделать 8–12 крупных YouTube-глав | PROPOSED | Навигация по темам без списка из 38 глав |
| Полный индекс вопросов вынести на публичную страницу | PROPOSED | Даёт детальную навигацию вне видеоплеера |
| Подготовить 2–3 обложки и названия для A/B-теста | PROPOSED | Проверять упаковку по данным, а не по ощущениям |

## Решения, которые блокируют монтаж

- [ ] Формат обработки повреждённого блока `35:00–42:00`.
- [ ] Конкретные границы исходного вступления и заключения.
- [ ] Список ответов, требующих досъёмки.
- [ ] Уровень раскрытия компании, вилки и личности собеседника.
- [ ] Состав CTA и статус публичной страницы.
