## Вывод, который проверяем

Не нужно вставлять все подготовленные состояния в каждый ответ. Библиотека экранов может быть полной, а конкретный монтаж выбирает только синхронные речи состояния и не больше одного редакционного дополнения. Для этого вопроса достаточно двух экранов по ответу и одного бонусного экрана во время мета-разговора.
