# Визуальная система выпуска

## База

- Приглушённая примерно на треть движущаяся фиолетово-розовая дымка.
- Анимированный аватар автора.
- Отдельный обезличенный аватар собеседника.
- Крупный текущий вопрос сверху.
- Центральная рабочая область для полезного материала.

## Правило для 16:9 и Shorts

- Не собирать полезную иллюстрацию в одну необрезаемую картинку на весь кадр.
  Код, подписи, схема и аватары должны оставаться отдельными слоями, чтобы
  монтажёр мог перестроить композицию под 9:16.
- Для 16:9 центральная область делится на две колонки: пример и 2–3 вывода.
  Для 9:16 те же блоки складываются вертикально, без уменьшения всего кадра.
- Схемы и предметные изображения помещать через `contain`; декоративный фон —
  через `cover`. Смысловой объект нельзя обрезать ради заполнения области.
- Ключевой текст и смысловой объект держать в центральной safe-зоне Shorts;
  аватары и вторичные подписи могут уходить ближе к краям.
- Один экран — один смысловой слой. Если ответ длинный, менять код, схему или
  тезис по ходу реплики, а не показывать полный ответ абзацем.
- Рабочий прототип: `mockups/readonly-frame.html` (переключатели 16:9/9:16 и
  «код + тезисы»/«адаптивная схема»).
