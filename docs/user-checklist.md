# Исходный чеклист автора

Этот файл сохраняет задачи автора отдельно от предложений, добавленных при
планировании.

- [ ] Валидация обложки.
- [ ] Решить, оставляем ли нетехнические моменты интервью — вступление и
  заключение. Автор склоняется к тому, чтобы вырезать их ради удержания и
  технического позиционирования канала: цель — привлекать опытных
  специалистов, а не продавать новичкам мечту «войти в IT».
- [ ] Решить, как обработать пропавший звук собеседника примерно на
  35–42 минутах:
  - вырезать фрагмент и заменить короткой вставкой автора «фрагмент потерян,
    спрашивали про это»;
  - либо восстановить реплики по ответам автора, при необходимости озвучить и
    явно подписать на экране, что звук повреждён, а реплика восстановлена.
- [ ] Написать тексты вступления и заключения.
- [ ] Подготовить экранные картинки и иллюстрации к техническим вопросам,
  чтобы видео было насыщеннее по пользе.
- [ ] Найти вопросы с плохими ответами и при необходимости доснять короткие
  вставки с правильным объяснением.
- [ ] Решить вопрос рекламы:
  - переводить ли зрителей на менторство;
  - показывать ли бесплатную платформу;
  - как объяснить ценность тренировки вопросов для техсобеседований;
  - делать ли публичной страницу с расшифровкой именно этого собеседования;
  - показывать ли возможность «пройти этот тех».
- [ ] Провалидировать оформление видеоряда и определить, что именно показывать
  на экране.
- [ ] Составить для монтажёра список технических вопросов с таймингами и
  соответствующими картинками.
- [ ] Придумать SEO-ориентированные название и описание ролика.
- [ ] Решить, нужна ли фоновая музыка.
- [ ] Решить детализацию таймкодов: подробные главы могут влиять на удержание,
  отсутствие навигации — на возвращаемость аудитории.
- [ ] Добавить в ТЗ монтажёру требование выписать таймкоды.
