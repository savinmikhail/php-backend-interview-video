# Редакционные решения

Все решения сначала получают статус `PROPOSED`, затем `ACCEPTED` или
`REJECTED`. Монтаж начинается после принятия решений уровня P0.

| Решение                                                      | Статус   | Обоснование                                               |
|--------------------------------------------------------------|----------|-----------------------------------------------------------|
| Удалить `00:00–13:46` исходного интервью                    | ACCEPTED | Начать с объяснения формата технических вопросов          |
| Удалить `01:02:45–01:17:20` исходного интервью              | ACCEPTED | Не раскрывать детали проекта компании                     |
| Анимировать аватар Михаила только на базовом экране          | ACCEPTED | Оживить пустые участки, не отвлекая от технических слайдов |
| Сделать собственный cold open длительностью 20–30 секунд     | PROPOSED | Быстро сформулировать обещание ролика                     |
| Повреждённый звук восстановить отдельно от экранной графики  | ACCEPTED | Вопросы выглядят обычно; способ ремонта звука решается отдельно |
| Доснимать только важные неправильные ответы                  | PROPOSED | Не раздувать хронометраж и стоимость монтажа              |
| Основной CTA — бесплатная платформа и «пройти этот тех»      | PROPOSED | Органично продолжает образовательную ценность             |
| Менторство оставить вторичным CTA                            | PROPOSED | Не прерывать техническое позиционирование прямой продажей |
| Сделать публичной отдельную безопасную страницу интервью     | PROPOSED | Нужна анонимизация и отсутствие административных данных   |
| Сделать 8–12 крупных YouTube-глав                            | PROPOSED | Навигация по темам без списка из 38 глав                  |
| Полный индекс вопросов вынести на публичную страницу         | PROPOSED | Даёт детальную навигацию вне видеоплеера                  |
